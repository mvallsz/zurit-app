I can modify a repacked package?

Of course you can edit a repacked package, The repacked packages are treated in the system as normal packages, The differences are mainly visual and associated with the ID of the package, since the repacked packages begin their ID with the RP prefix (RP-XXXXXXXX). I remind you that you can only edit packages with status = "In Warehouse", also remember that once the package is associated with a guide, this cannot be altered.


Follow the steps below to edit a package:


  • - Go to the Warehouse Inventory module
  • - Once the package list is showed, look for the package you want to edit
  • - To access the packet editing module you can do clik in the row of the table associated with the package or from the Action menu, click on edit option.
  • - Once in the package editing module, you can modify the fields you want
  • - After editing just click in the UPDATE PACKAGE button
